## Critical: `npm run build` từng phá shipped functionality — ĐÃ FIX trong audit

**Resolved tại thời điểm audit.** Bốn artifacts được đăng ký thành passthrough entries trong `runtime-src/manifest.json` và lưu dưới `runtime-src/build/`, để `scripts/build-runtime.mjs` restore sau webpack như với các hand-authored runtime khác.

Passthrough count tăng từ 7 lên 13. `build-runtime.mjs` cũng được đổi để drop mọi `*.asset.php` không được runtime manifest claim, thay vì special-case một filename.

Verification được ghi: chạy `npm run build` hai lần từ clean tree và xác nhận `git status` không báo modification ở bốn file.

Diagnosis gốc vẫn được giữ vì underlying condition — build output committed khác declared source — là điều không được tái tạo.

### Original finding

Trước fix, chạy documented build command trên clean checkout âm thầm thay bốn committed outputs bằng file nhỏ hơn. Source tree không reproduce đúng plugin đang ship.

| Output | Committed | Rebuilt from `src/` | Lost |
| --- | ---: | ---: | ---: |
| `build/preview.js` | 15,809 | 4,730 | 70% |
| `build/standalone-ai-bridge.js` | 18,124 | 10,919 | 40% |
| `build/widget-control-enhancements.js` | 14,122 | 7,897 | 44% |
| `build/container.js` | 16,170 | 9,769 | 40% |

Đây không phải minification variance.

`scripts/check-editor-runtime.mjs` yêu cầu `build/widget-control-enhancements.js` chứa:

- `Choose a structured preset`
- `aria-pressed`
- `sessionStorage`
- `.cc-standalone-left-content`
- `observer.disconnect()`
- `pagehide`

**Không string nào trong sáu string này tồn tại trong `src/standalone/widget-control-enhancements.js` ở baseline đó.** Shipped artifact chứa behavior source không mô tả, cho thấy artifact từng bị edit trực tiếp mà source không sync.

`scripts/build-runtime.mjs` restore hand-maintained `runtime-src/build/` outputs sau webpack, vì vậy family đó sống sót. Bốn file lỗi khi đó bị xem là webpack-owned nên không có protection tương ứng.

Consequences được audit ghi trước khi fix:

- `npm run build` là destructive trên `main` ở baseline đó, kể cả CI có thể ship regression mà không error;
- `check:editor-runtime` pass chỉ vì stale artifacts committed, rồi fail ngay khi build chạy — ngược với ý nghĩa build gate;
- reproducible-build và `SHA256SUMS` claims trong `docs/RELEASE_ENGINEERING.md` không đúng cho bốn output này ở baseline đó.

Root cause được mô tả: cả bốn committed artifacts là hand-authored, framework-free IIFEs viết với `wp.*` globals, không phải webpack output. `build/preview.js` là hand-transpiled twin của `src/preview/index.tsx`; hai bên drift và hand-written side là bên ship. Chúng bị khai trong `manifest.generated` như webpack-owned nên không được restore sau build.

## Phase 1 findings và remediation

- `HistoryManager` thực ra đã protect cả bốn history routes. Nó reuse hai route option arrays, mỗi array chứa `permission_callback => can_edit_post`; old checker đếm literal callback tokens thay vì protected registrations. `check-production-hardening` được sửa để hiểu reusable route configs, và `RestPermissionsTest` exercise cả bốn registered callbacks.
- Container serialized React style contract là `backgroundColor`, như `styleFromAttributes()`/`save.tsx` dùng. Unit test expect `background` là stale và được sửa theo shipped serialization key.
- Release packaging thêm explicit retired-asset deny list gồm `build/native-gutenberg-bridge.js` và asset metadata.
- Studio quality checks nhận `crescoDocumentStore` là sole revision/session-change owner. Reintroduce `state.revision++` hoặc Session listener trong consistency guard được coi là regression thay vì required token.
- Responsive-properties checker bảo vệ shipped `widget-aware-responsive-accordion` behavior và tiếp tục từ chối drag/persistence ownership.
- Website Builder responsive checks bảo vệ `ResponsiveResolver` như shared breakpoint authority thay vì yêu cầu removed hard-coded range tuples.
- `build/website-builder-document-store.js` được thêm production allowlist, khớp `runtime-src/manifest.json` ownership.
- Architecture check chọn `C:\xampp\php\php.exe` mặc định trên Windows, cho phép override bằng `CRESCO_PHP_BINARY`, để documented XAMPP environment chạy PHP syntax check mà không cần đổi PATH.

`RenderEngine/v2` vẫn là canonical renderer.

Parity/deprecation regression test render shared Session qua `WebsiteRenderer` và `WebsiteRendererV2`, verify common markup subset và ghi riêng known CSS divergence:

- legacy compiler: `width:100%`;
- canonical full-container: `width:auto`.

`WebsiteRenderer` chưa thể delete ở thời điểm đó vì `WebsiteRendererV2::legacy_fragment()` vẫn delegate unsupported fragments cho nó. Xóa ngay sẽ là functional regression, không phải consolidation.

Lý do: Studio bundle khi đó có local React document state và không có inbound mutation subscription từ `crescoDocumentStore`; hand-edit minified bundle sẽ vi phạm source-ownership rule.

Safe next step được ghi: migrate một runtime nhỏ sang `src/`, chạy legacy/new behavior suite trên cả hai implementation, rồi mới switch manifest owner.

## Phase 3 progress và blockers

Local-only Playwright capture utility được thêm, consume existing `cresco-ai-visual/v1` standalone document và capture Wide, Desktop, Laptop, Tablet, Mobile screenshots.

Nó reject non-local REST endpoints và block non-local browser requests để visual capture không trở thành implicit external API/data-exfiltration path.

SDK write channel và Responsive **Reset override** button được intentionally block bởi Studio runtime migration nói trên.

`CrescoStudioSDK.dispatch()` lúc đó chỉ emit extension events; Studio React tree không có supported inbound API để replace local Session.

Chỉ thêm mutation method vào DocumentStore sẽ update store nhưng visible Studio state vẫn stale, tạo dual-authority defect khác. Audit yêu cầu giải quyết trong typed Studio owner, không bằng DOM mutation hoặc hand patch compressed artifact.
