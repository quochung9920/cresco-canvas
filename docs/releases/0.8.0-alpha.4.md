# Cresco Canvas 0.8.0-alpha.4

## Added

- A server-rendered **ACF Repeater** block that repeats one native Gutenberg block template for up to 24 associative rows.
- A server-rendered **ACF Flexible Content** block that maps `acf_fc_layout` values to child Layout Template blocks.
- An **ACF Layout Template** child block with an optional `fallback` layout for unmapped rows.
- An **ACF Sub Field** block with safe dot-path access up to four array levels, plus fallback text and allow-listed HTML tags.
- A permission-protected ACF field catalog endpoint that returns field names, labels, types, and Flexible Content layout names without returning field values.
- A separate server-rendered **Advanced Loop** block for bounded post, author, parent, search, date, include/exclude ID, taxonomy, and meta queries.
- Up to three taxonomy filters, each limited to 24 term slugs and restricted to taxonomies assigned to the selected public post type.
- One bounded meta-query clause with allow-listed compare and data-type values.
- Meta-value and numeric-meta ordering only when a sanitized meta key exists.
- Advanced Loop pagination with a per-block sanitized public query parameter.
- Checked-in Gutenberg controls and shared frontend/editor styles for all alpha.4 blocks.
- Regression test source for row limits, dot paths, layout mapping, ID/date normalization, and invalid taxonomy-filter shapes.

## REST API

- `GET /wp-json/cresco-canvas/v1/dynamic/acf-fields`
- `GET /wp-json/cresco-canvas/v1/dynamic/advanced-query-options`
- `POST /wp-json/cresco-canvas/v1/dynamic/advanced-query-preview`

All routes require Page editing capability. A post-scoped ACF catalog request additionally requires edit access to the requested post.

## Security and performance

- Repeater and Flexible Content collections are limited to 24 rows.
- Sub-field paths are limited to four sanitized array segments and never traverse objects.
- Advanced queries are restricted to public post types and published posts.
- Item count is limited to 24, pages to 999, include/exclude lists to 24 IDs, and taxonomy filters to three clauses.
- Search and meta values have bounded lengths.
- Meta comparison and type values are allow-listed; arbitrary SQL fragments are not accepted.
- Taxonomies must exist and be assigned to the selected post type.
- Nested Advanced Loops stop after one active loop depth.
- ACF schema discovery returns definitions only and never raw field values.

## Packaging

Release packages require:

- `build/dynamic-alpha4.js`
- `build/dynamic-alpha4.asset.php`
- `assets/css/dynamic-alpha4.css`

## Known limitations

- Repeater and Flexible Content rendering currently targets scalar sub-fields; dedicated nested image, gallery, relationship, and nested repeater row bindings remain future work.
- Flexible Content templates are matched by `acf_fc_layout` and use one child block template per layout; automatic template generation is not included.
- Advanced Loop supports one meta-query clause and up to three taxonomy clauses, not arbitrary nested query groups.
- AJAX filtering, faceted search, load-more, infinite scroll, URL history synchronization, and WooCommerce query presets are not included.
- The checked-in runtimes have not been rebuilt from the TypeScript source pipeline because the repository dependency lock/build environment remains unavailable.
- Hosted CI, WordPress/ACF runtime, accessibility, RTL, multisite, browser, and performance verification are not yet available for the current `main` head.
- This is an alpha source/runtime candidate, not a production-verified stable release.
