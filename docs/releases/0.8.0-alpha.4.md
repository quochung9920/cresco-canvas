# Cresco Canvas 0.8.0-alpha.4

> Release note lịch sử. Các capability và giới hạn bên dưới thuộc đúng phiên bản này.

## Đã thêm

- Server-rendered **ACF Repeater** block lặp một native Gutenberg block template cho tối đa 24 associative rows.
- Server-rendered **ACF Flexible Content** block map `acf_fc_layout` values sang child Layout Template blocks.
- **ACF Layout Template** child block với optional `fallback` layout cho unmapped rows.
- **ACF Sub Field** block với safe dot-path access tối đa bốn array levels, cùng fallback text và allow-listed HTML tags.
- Permission-protected ACF field catalog endpoint chỉ trả field names, labels, types và Flexible Content layout names, không trả field values.
- Server-rendered **Advanced Loop** riêng cho bounded post, author, parent, search, date, include/exclude ID, taxonomy và meta queries.
- Tối đa ba taxonomy filters, mỗi filter tối đa 24 term slugs và chỉ dùng taxonomy được gán cho selected public post type.
- Một bounded meta-query clause với allow-listed compare/data-type values.
- Meta-value và numeric-meta ordering chỉ khi có sanitized meta key.
- Advanced Loop pagination với per-block sanitized public query parameter.
- Checked-in Gutenberg controls và shared frontend/editor styles cho toàn bộ alpha.4 blocks.
- Regression test source cho row limits, dot paths, layout mapping, ID/date normalization và invalid taxonomy-filter shapes.

## REST API

- `GET /wp-json/cresco-canvas/v1/dynamic/acf-fields`
- `GET /wp-json/cresco-canvas/v1/dynamic/advanced-query-options`
- `POST /wp-json/cresco-canvas/v1/dynamic/advanced-query-preview`

Tất cả route yêu cầu Page editing capability. Post-scoped ACF catalog request còn yêu cầu edit access tới requested post.

## Bảo mật và hiệu năng

- Repeater/Flexible Content collections giới hạn 24 rows.
- Sub-field paths giới hạn bốn sanitized array segments và không traverse objects.
- Advanced queries chỉ dùng public post types và published posts.
- Item count tối đa 24, page tối đa 999, include/exclude tối đa 24 IDs, taxonomy filters tối đa ba clauses.
- Search/meta values có bounded length.
- Meta comparison/type values dùng allow-list; arbitrary SQL fragments không được chấp nhận.
- Taxonomy phải tồn tại và được gán cho selected post type.
- Nested Advanced Loops dừng sau một active loop depth.
- ACF schema discovery chỉ trả definitions, không trả raw field values.

## Giới hạn đã biết

- Repeater/Flexible Content chủ yếu target scalar sub-fields; dedicated nested image/gallery/relationship/nested repeater row bindings còn là future work.
- Flexible Content template match bằng `acf_fc_layout` và dùng một child block template cho mỗi layout; chưa có automatic template generation.
- Advanced Loop hỗ trợ một meta-query clause và tối đa ba taxonomy clauses, không hỗ trợ arbitrary nested query groups.
- AJAX filtering, faceted search, load-more, infinite scroll, URL history synchronization và WooCommerce query presets chưa có.
- Checked-in runtimes chưa được rebuild từ TypeScript source pipeline vì dependency lock/build environment chưa khả dụng ở thời điểm đó.
- Hosted CI, WordPress/ACF runtime, accessibility, RTL, multisite, browser và performance verification chưa có cho `main` head tại thời điểm đó.
- Đây là alpha source/runtime candidate, **không phải production-verified stable release**.
