# Cresco Canvas 0.9.0-alpha.3

## Added

- Secure multipart form submission endpoint.
- File upload validation with a 5 MB limit and an explicit MIME allow-list.
- Uploaded file attachment metadata for lifecycle management.
- Signed webhooks using `X-Cresco-Signature` with bounded exponential retries.
- Webhook failure logs limited to the latest 100 entries.
- Reply-To mapping from a validated email field.
- Declarative conditional field rendering and frontend evaluation.
- Popup rules for delay, scroll depth, and exit intent.
- Slider pointer swipe, pagination dots, autoplay pause/resume, and responsive state updates.
- Regression tests for signed form payloads and field normalization.

## Security boundaries

- The multipart endpoint verifies the signed form schema before processing values or files.
- Uploads are limited to JPEG, PNG, GIF, WebP, PDF, TXT, and CSV.
- Executable file types are rejected.
- Webhook bodies are signed with a site-specific HMAC.
- Retry attempts are capped at three.
- Conditional fields can only reference sanitized field names and supported operators.

## Known limitations

- CAPTCHA providers are not included yet.
- Multi-step and calculated forms are not included yet.
- Webhook secrets are site-derived and do not yet support per-form secret rotation.
- Uploaded attachment cleanup/retention requires further administration controls.
- CRM-specific adapters and Gravity Forms migration are not included yet.
- Source and checked-in runtimes are not production-verified because CI/runtime verification is deferred.
