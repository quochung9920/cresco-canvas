# Cresco Canvas 0.9.0-alpha.3

> Release note lịch sử. Nội dung mô tả đúng capability/security boundary của phiên bản này.

## Đã thêm

- Secure multipart form submission endpoint.
- File upload validation với giới hạn 5 MB và explicit MIME allow-list.
- Uploaded file attachment metadata cho lifecycle management.
- Signed webhooks bằng `X-Cresco-Signature` với bounded exponential retries.
- Webhook failure logs giới hạn latest 100 entries.
- Reply-To mapping từ validated email field.
- Declarative conditional field rendering và frontend evaluation.
- Popup rules cho delay, scroll depth và exit intent.
- Slider pointer swipe, pagination dots, autoplay pause/resume và responsive state updates.
- Regression tests cho signed form payloads và field normalization.

## Security boundaries

- Multipart endpoint verify signed form schema trước khi xử lý values/files.
- Upload chỉ cho JPEG, PNG, GIF, WebP, PDF, TXT và CSV.
- Executable file types bị từ chối.
- Webhook body được sign bằng site-specific HMAC.
- Retry attempts tối đa ba lần.
- Conditional fields chỉ được reference sanitized field names và supported operators.

## Giới hạn đã biết

- CAPTCHA providers chưa có.
- Multi-step và calculated forms chưa có.
- Webhook secrets dùng site-derived secret và chưa support per-form secret rotation.
- Uploaded attachment cleanup/retention còn cần thêm administration controls.
- CRM-specific adapters và Gravity Forms migration chưa có.
- Source/checked-in runtimes chưa production-verified vì CI/runtime verification được defer ở thời điểm đó.
