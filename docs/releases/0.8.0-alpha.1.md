# Cresco Canvas 0.8.0-alpha.1

> Release note lịch sử của milestone Dynamic Data đầu tiên.

## Đã thêm

- Server-rendered **Dynamic Field** block cho post, site, custom-field và ACF values.
- Server-rendered **Cresco Loop** block lặp native inner blocks theo một bounded WordPress query.
- Dynamic post fields cho title, excerpt, content text, date, modified date, author, permalink và featured-image URL.
- Custom-field support qua post meta và optional ACF integration bằng `get_field()` khi ACF active.
- ACF-compatible fallback sang post meta khi ACF không khả dụng.
- Query controls cho public post type, item limit, offset, order, orderby, taxonomy, term và responsive-friendly column count.
- REST discovery và query-preview endpoints.
- Checked-in Gutenberg runtime và stylesheet cho Dynamic Field/Loop editing.
- Regression coverage cho bounded và allow-listed query arguments.

## REST API

- `GET /wp-json/cresco-canvas/v1/dynamic/options`
- `POST /wp-json/cresco-canvas/v1/dynamic/query-preview`

Cả hai route yêu cầu Page editing capability.

## Bảo mật và hiệu năng

- Query post types bị giới hạn vào public WordPress post types.
- Query result chỉ lấy published content.
- Item count tối đa 24, offset tối đa 200.
- `orderby` dùng allow-list; arbitrary SQL/meta ordering bị từ chối.
- Taxonomy filter chỉ được thêm khi taxonomy tồn tại và được gán cho selected post type.
- Dynamic keys được normalize bằng `sanitize_key()`.
- Dynamic values được chuyển thành scalar text và escape trước frontend output.
- Loop rendering reset global post data sau mỗi query.

## Packaging

Release package yêu cầu:

- `build/dynamic.js`
- `build/dynamic.asset.php`
- `assets/css/dynamic.css`

## Giới hạn đã biết

- Đây là bounded Query/Loop và scalar data-binding layer đầu tiên, không phải arbitrary SQL builder tổng quát.
- ACF repeater, flexible-content, relationship, gallery và structured object renderers chưa có trong alpha này.
- Dynamic image mới expose featured-image URL như scalar field, chưa có dedicated image binding control.
- Pagination, AJAX filtering, nested loop protection, faceted search và WooCommerce product-query presets còn là future work.
- Hosted CI, full WordPress runtime, ACF compatibility, accessibility, RTL, browser, multisite và performance verification chưa có cho `main` head tại thời điểm đó.
- Đây là alpha source/runtime candidate, **không phải production-verified stable release**.
