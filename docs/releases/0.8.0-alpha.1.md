# Cresco Canvas 0.8.0-alpha.1

## Added

- A server-rendered **Dynamic Field** block for post, site, custom-field, and ACF values.
- A server-rendered **Cresco Loop** block that repeats native inner blocks for a bounded WordPress query.
- Dynamic post fields for title, excerpt, content text, date, modified date, author, permalink, and featured-image URL.
- Custom-field support through post meta and optional ACF integration through `get_field()` when ACF is active.
- ACF-compatible fallback to post meta when ACF is unavailable.
- Query controls for public post type, item limit, offset, order, orderby, taxonomy, term, and responsive-friendly column count.
- REST discovery and query-preview endpoints.
- A checked-in Gutenberg runtime and stylesheet for Dynamic Field and Loop editing.
- Regression coverage for bounded and allow-listed query arguments.

## REST API

- `GET /wp-json/cresco-canvas/v1/dynamic/options`
- `POST /wp-json/cresco-canvas/v1/dynamic/query-preview`

Both routes require Page editing capability.

## Security and performance

- Query post types are restricted to public WordPress post types.
- Query results are restricted to published content.
- Item count is limited to 24 and offset to 200.
- `orderby` values are allow-listed and arbitrary SQL/meta ordering is rejected.
- Taxonomy filters are added only when the taxonomy exists and is assigned to the selected post type.
- Dynamic keys are normalized with `sanitize_key()`.
- Dynamic values are converted to scalar text and escaped before frontend output.
- Loop rendering resets global post data after every query.

## Packaging

Release packages require:

- `build/dynamic.js`
- `build/dynamic.asset.php`
- `assets/css/dynamic.css`

## Known limitations

- This release provides the first bounded Query/Loop and scalar data-binding layer; it is not a general arbitrary SQL builder.
- ACF repeater, flexible-content, relationship, gallery, and structured object renderers are not included in this alpha.
- Dynamic images currently expose the featured-image URL as a scalar field rather than a dedicated image binding control.
- Pagination, AJAX filtering, nested loop protection, faceted search, and WooCommerce product-query presets remain future work.
- Hosted CI, full WordPress runtime, ACF compatibility, accessibility, RTL, browser, multisite, and performance verification are not yet available for the current `main` head.
- This is an alpha source/runtime candidate, not a production-verified stable release.
