# Cresco Canvas 0.9.0-rc.1

## Functional scope

This release candidate completes the planned 0.9 interaction and form-builder scope at source and checked-in runtime level.

### Interactive components

- Tabs and accordions with keyboard navigation.
- Modal and off-canvas dialogs with focus trapping.
- Popup triggers for click, delay, scroll depth, and exit intent.
- Slider/carousel arrows, dots, autoplay, responsive slides per view, and pointer swipe.
- Disclosure, tooltip, sticky, and conditional-visibility blocks.

### Forms

- Native form and field blocks.
- Server validation, signed form schemas, honeypot, and rate limiting.
- Submission storage, email delivery, CSV export, privacy exporter/eraser, and retention.
- Secure multipart uploads with bounded MIME types and sizes.
- Signed webhook delivery with retry and failure logs.
- Conditional fields.
- Multi-step form panels.
- Calculated fields using a bounded arithmetic grammar.
- Provider-neutral CAPTCHA adapter for Turnstile, reCAPTCHA v3, and hCaptcha.
- Daily cleanup for orphaned Cresco form uploads.
- Form diagnostics for duplicate field names, invalid formulas, and incomplete CAPTCHA configuration.
- Extension hooks for CAPTCHA verification, webhook delivery, CRM adapters, and migration tooling.

## Release status

The 0.9 functional scope is complete at source and checked-in runtime level. Hosted CI, complete WordPress runtime verification, provider-specific CAPTCHA verification adapters, and production compatibility certification remain deferred to 1.0 hardening.
