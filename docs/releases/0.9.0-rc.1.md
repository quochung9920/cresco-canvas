# Cresco Canvas 0.9.0-rc.1

> Release note lịch sử của release candidate 0.9.

## Functional scope

Release candidate này hoàn tất planned 0.9 interaction/form-builder scope ở mức source và checked-in runtime.

### Interactive components

- Tabs/Accordion với keyboard navigation.
- Modal/Off-canvas dialogs với focus trapping.
- Popup triggers cho click, delay, scroll depth và exit intent.
- Slider/Carousel với arrows, dots, autoplay, responsive slides per view và pointer swipe.
- Disclosure, Tooltip, Sticky và Conditional Visibility blocks.

### Forms

- Native Form và Form Field blocks.
- Server validation, signed form schemas, honeypot và rate limiting.
- Submission storage, email delivery, CSV export, privacy exporter/eraser và retention.
- Secure multipart uploads với bounded MIME types/sizes.
- Signed webhook delivery với retry và failure logs.
- Conditional fields.
- Multi-step form panels.
- Calculated fields dùng bounded arithmetic grammar.
- Provider-neutral CAPTCHA adapter cho Turnstile, reCAPTCHA v3 và hCaptcha.
- Daily cleanup cho orphaned Cresco form uploads.
- Form diagnostics cho duplicate field names, invalid formulas và incomplete CAPTCHA configuration.
- Extension hooks cho CAPTCHA verification, webhook delivery, CRM adapters và migration tooling.

## Trạng thái release

Functional scope 0.9 được coi complete ở mức source/checked-in runtime. Hosted CI, complete WordPress runtime verification, provider-specific CAPTCHA verification adapters và production compatibility certification vẫn được defer sang 1.0 hardening tại thời điểm release note này.
