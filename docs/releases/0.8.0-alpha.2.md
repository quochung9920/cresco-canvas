# Cresco Canvas 0.8.0-alpha.2

## Added

- A server-rendered **Dynamic Image** block for featured images, post-meta image values, and ACF image fields.
- Support for common image return formats: attachment ID, URL, and ACF-style arrays containing ID, URL, and alt text.
- Image-size, fallback URL, fallback alt text, alignment, spacing, and current-post link controls.
- Server-side Loop pagination with a configurable, sanitized query-string parameter.
- Query presets for recent, oldest, alphabetical, random, and custom ordering.
- Nested Loop protection in both the Gutenberg allowed-block list and the server renderer.
- Query preview metadata for the current page and total page count.
- Accessible pagination navigation and responsive Dynamic Image styles.
- Regression coverage for pagination bounds, deterministic query presets, page-parameter sanitation, and empty image resolution.

## Changed

- Loop offset now acts as a base offset and is combined with the normalized page number.
- Query pages are bounded to 999 and calculated offsets are bounded to 2,000.
- The default Loop template now includes Dynamic Image, linked Dynamic Title, and Dynamic Excerpt.
- Dynamic discovery options now expose image sources, image sizes, query presets, and the nested-loop limit.
- The checked-in Dynamic Data runtime and manifest were advanced to `0.8.0-alpha.2`.

## Security and performance

- Image field keys and pagination parameter names are normalized before use.
- External fallback and field URLs are passed through WordPress URL sanitation and escaping.
- Attachment images use WordPress responsive image markup when an attachment ID is available.
- Nested Cresco Loops stop rendering after one active Loop depth, preventing recursive query expansion.
- Query item, page, base-offset, and calculated-offset limits remain enforced server-side.

## Known limitations

- Pagination performs a full page reload; AJAX filtering and infinite scroll are not included.
- ACF repeater, flexible-content, relationship, and gallery renderers remain outside this alpha.
- Multiple loops on one page require different pagination parameter values to paginate independently.
- Query presets do not include arbitrary meta queries or arbitrary SQL fragments.
- Hosted CI, WordPress/ACF runtime, accessibility, RTL, multisite, browser, and performance evidence are not yet available for the current `main` head.
- This is an alpha source/runtime candidate, not a production-verified stable release.
