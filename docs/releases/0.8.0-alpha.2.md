# Cresco Canvas 0.8.0-alpha.2

> Release note lịch sử. Các giới hạn/status bên dưới chỉ áp dụng cho phiên bản này.

## Đã thêm

- Server-rendered **Dynamic Image** block cho featured images, post-meta image values và ACF image fields.
- Hỗ trợ common image return formats: attachment ID, URL và ACF-style arrays có ID, URL, alt text.
- Controls cho image size, fallback URL, fallback alt text, alignment, spacing và current-post link.
- Server-side Loop pagination với configurable, sanitized query-string parameter.
- Query presets cho recent, oldest, alphabetical, random và custom ordering.
- Nested Loop protection trong cả Gutenberg allowed-block list và server renderer.
- Query preview metadata cho current page và total page count.
- Accessible pagination navigation và responsive Dynamic Image styles.
- Regression coverage cho pagination bounds, deterministic query presets, page-parameter sanitation và empty image resolution.

## Đã thay đổi

- Loop offset trở thành base offset và được cộng với normalized page number.
- Query pages bị giới hạn 999 và calculated offsets bị giới hạn 2,000.
- Default Loop template gồm Dynamic Image, linked Dynamic Title và Dynamic Excerpt.
- Dynamic discovery options expose image sources, image sizes, query presets và nested-loop limit.
- Checked-in Dynamic Data runtime/manifest được nâng lên `0.8.0-alpha.2`.

## Bảo mật và hiệu năng

- Image field keys và pagination parameter names được normalize trước khi dùng.
- External fallback/field URLs đi qua WordPress URL sanitation và escaping.
- Attachment images dùng WordPress responsive image markup khi có attachment ID.
- Nested Cresco Loops dừng render sau một active Loop depth để tránh recursive query expansion.
- Query item/page/base-offset/calculated-offset limits tiếp tục được enforce server-side.

## Giới hạn đã biết

- Pagination reload toàn page; chưa có AJAX filtering/infinite scroll.
- ACF repeater, flexible-content, relationship và gallery renderers vẫn ngoài scope alpha này.
- Nhiều loop trên cùng page cần pagination parameter khác nhau để paginate độc lập.
- Query presets không hỗ trợ arbitrary meta query hoặc arbitrary SQL fragments.
- Hosted CI, WordPress/ACF runtime, accessibility, RTL, multisite, browser và performance evidence chưa có cho `main` head tại thời điểm đó.
- Đây là alpha source/runtime candidate, **không phải production-verified stable release**.
