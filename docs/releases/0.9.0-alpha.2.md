# Cresco Canvas 0.9.0-alpha.2

> Release note lịch sử của interaction/form milestone 0.9.

## Đã thêm

- Gutenberg inserter và Inspector controls cho Tabs, Accordion, Modal, Slider/Carousel, Off-canvas, Disclosure, Tooltip, Sticky, Conditional Visibility, Form và Form Field blocks.
- Modal trigger controls cho click, delay, scroll depth và exit intent configuration.
- Slider controls cho autoplay, interval, looping, arrows, dots và pause-on-hover.
- Conditional visibility controls cho login state, dates, device hints và query parameters.
- Conditional form-field configuration.
- Form notification, reply-to, redirect, webhook, retention và submission-storage controls.
- Submission admin columns, bounded CSV export, scheduled retention và WordPress privacy exporter/eraser integration.
- Checked-in editor runtime, manifest và editor preview stylesheet.
- Release-package requirements cho toàn bộ 0.9 interaction/form runtimes.

## Foundation 0.9 đã có

- Accessible server-rendered Tabs, Accordion, Modal, Slider, Off-canvas, Disclosure, Tooltip, Sticky và Conditional Visibility components.
- Native Form/Form Field blocks với signed schema, server validation, storage, email notification, honeypot và anonymous rate limiting.
- Frontend interaction/form runtimes với progressive enhancement.

## Security và bounds

- Form configuration vẫn nằm trong server signature.
- Submitted fields bị giới hạn bởi signed schema.
- Select/radio/checkbox values tiếp tục dùng allow-list.
- Submission export yêu cầu `manage_options` và valid nonce.
- CSV export tối đa 5,000 records/request.
- Retention processing tối đa 500 records/scheduled run.

## Giới hạn đã biết

- Editor controls là checked-in runtime code và chưa được reproduce từ TypeScript build pipeline ở thời điểm đó.
- File-input markup có sẵn nhưng multipart upload persistence và attachment lifecycle chưa complete.
- Webhook controls đã expose nhưng delivery signing, retries và logs chưa complete.
- Popup display rules và advanced slider settings cần frontend-runtime expansion tương ứng trước khi được coi complete.
- Multi-step forms, calculated fields, CAPTCHA providers, CRM-specific adapters và visual email templates còn là future 0.9 work.
- Hosted CI và full WordPress/browser/accessibility runtime verification chưa khả dụng.

Đây là alpha source/runtime candidate, **không phải production-verified stable release**.
