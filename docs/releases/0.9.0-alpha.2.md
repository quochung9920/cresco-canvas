# Cresco Canvas 0.9.0-alpha.2

## Added

- Gutenberg inserter and Inspector controls for Tabs, Accordion, Modal, Slider/Carousel, Off-canvas, Disclosure, Tooltip, Sticky, Conditional Visibility, Form, and Form Field blocks.
- Modal trigger controls for click, delay, scroll depth, and exit intent configuration.
- Slider controls for autoplay, interval, looping, arrows, dots, and pause-on-hover.
- Conditional visibility controls for login state, dates, device hints, and query parameters.
- Conditional form-field configuration.
- Form notification, reply-to, redirect, webhook, retention, and submission-storage controls.
- Submission admin columns, bounded CSV export, scheduled retention, and WordPress privacy exporter/eraser integration.
- Checked-in editor runtime, manifest, and editor preview stylesheet.
- Release-package requirements for all 0.9 interaction and form runtimes.

## Existing 0.9 foundation

- Accessible server-rendered Tabs, Accordion, Modal, Slider, Off-canvas, Disclosure, Tooltip, Sticky, and Conditional Visibility components.
- Native Form and Form Field blocks with signed schema, server validation, storage, email notification, honeypot, and anonymous rate limiting.
- Frontend interaction and form runtimes with progressively enhanced behavior.

## Security and bounds

- Form configuration remains covered by a server signature.
- Submitted fields are restricted to the signed schema.
- Select, radio, and checkbox values remain allow-listed.
- Submission export requires `manage_options` and a valid nonce.
- CSV export is bounded to 5,000 records per request.
- Retention processing is bounded to 500 records per scheduled run.

## Known limitations

- Editor controls are checked-in runtime code and have not been reproduced from the TypeScript build pipeline.
- File-input markup exists, but multipart upload persistence and attachment lifecycle handling are not yet complete.
- Webhook controls are exposed, but delivery signing, retries, and logs are not yet complete.
- Popup display rules and advanced slider settings require matching frontend-runtime expansion before being considered complete.
- Multi-step forms, calculated fields, CAPTCHA providers, CRM-specific adapters, and visual email templates remain future 0.9 work.
- Hosted CI and full WordPress/browser/accessibility runtime verification remain unavailable.

This is an alpha source/runtime candidate and not a production-verified stable release.
