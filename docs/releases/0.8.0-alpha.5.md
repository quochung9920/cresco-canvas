# Cresco Canvas 0.8.0-alpha.5

> Release note lịch sử. Nội dung này chỉ mô tả `0.8.0-alpha.5`.

## Đã thêm

- Server-rendered **Filterable Loop** block với progressively enhanced AJAX pagination.
- Load More và Infinite Scroll interaction modes.
- Search và tối đa ba public taxonomy facets.
- Per-loop URL/browser-history synchronization bằng scoped query-string keys.
- Signed public REST render endpoint chỉ nhận server-created query payload và declared filters.
- Request cancellation và sequence checks để stale AJAX response không thay kết quả mới hơn.
- No-JavaScript GET filtering và pagination fallbacks.
- WooCommerce query presets cho newest, featured, on-sale, in-stock, best-selling và top-rated products.
- Conservative anonymous request rate limit.
- Checked-in editor/frontend runtimes với responsive filter, result-grid, pagination, loading, error, Load More và Infinite Scroll states.
- Regression test source cho signatures, filter allow-lists, interaction modes, WooCommerce preset names, instance IDs, template restrictions và bounded payloads.

## REST API

- `POST /wp-json/cresco-canvas/v1/dynamic/interactive-query`

Endpoint public vì phục vụ frontend visitors. Mỗi request phải có HMAC signature hợp lệ cho exact server-created payload. Thay query arguments hoặc block markup sẽ làm signature invalid.

## Bảo mật và hiệu năng

- Public request chỉ được đổi search text, declared taxonomy facets và bounded page number.
- Query arguments, block markup, WooCommerce preset, post type, item count và static constraints đều nằm trong signature.
- Templates chỉ cho Core/Cresco blocks và từ chối executable, third-party, recursive query block types.
- Advanced Loop bounds vẫn được enforce: public post types, published posts, tối đa 24 items, page tối đa 999, bounded meta/tax clauses, không arbitrary SQL.
- Facet taxonomies phải tồn tại và được gán cho configured post type.
- Taxonomy terms normalize và giới hạn 24 values mỗi declared facet.
- Search text tối đa 100 ký tự.
- Public AJAX requests tối đa 120 request/phút trên mỗi hashed client address.
- Frontend dùng `AbortController` khi có và bỏ stale response sequence.

## Progressive enhancement

- Có JavaScript: filter update result không reload document.
- AJAX mode thay current result page.
- Load More/Infinite Scroll append next result page.
- URL synchronization lưu scoped search/facet/page state và restore khi browser back/forward.
- Không JavaScript: filter form submit GET và standard pagination links vẫn hoạt động.

## Giới hạn đã biết

- Facets chưa tính live per-option result count.
- Runtime meta facets, range sliders, active-filter chips và dependent facet counts chưa có.
- Nhiều Filterable Loop giống nhau trên cùng page nên dùng unique Instance IDs để tránh URL-key collision.
- On-sale WooCommerce preset dùng bounded list từ WooCommerce và có thể không giữ independent static include-ID ordering.
- Dedicated image/gallery/relationship/nested repeater sub-field bindings trong Repeater/Flexible rows còn là future work.
- Checked-in runtimes chưa được reproduce từ TypeScript build pipeline vì build environment/dependency lock chưa khả dụng ở thời điểm đó.
- Hosted CI, WordPress/ACF/WooCommerce runtime, accessibility, RTL, multisite, browser, security và performance verification chưa có cho `main` head tại thời điểm đó.
- Đây là alpha source/runtime candidate, **không phải production-verified stable release**.
