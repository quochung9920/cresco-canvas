# Cresco Canvas 0.8.0-rc.1

## Scope completed

This release candidate completes the planned 0.8 Dynamic Data milestone at source and checked-in runtime level.

Implemented across the 0.8 series:

- Dynamic scalar, image, gallery, relationship, repeater, flexible-content, and sub-field bindings.
- Dedicated row image, row gallery, and row relationship bindings inside Repeater and Flexible Content templates.
- Standard, advanced, and filterable Loop builders.
- Bounded author, parent, search, date, include/exclude ID, taxonomy, and meta queries.
- Server-side pagination, AJAX pagination, Load More, Infinite Scroll, URL/history synchronization, and no-JavaScript fallbacks.
- Signed public query payloads, filter allow-lists, template allow-lists, and anonymous rate limiting.
- Taxonomy facets, dependent live option counts, active-filter chips, and Clear All controls.
- WooCommerce presets for newest, featured, on-sale, in-stock, best-selling, and top-rated products.
- ACF field schema discovery without raw-value exposure.
- Post-scoped Dynamic Data diagnostics for duplicate Filterable Loop Instance IDs, missing row paths, and loops with no enabled filters.

## Security and bounds

- Facet-count requests require the exact HMAC-signed server payload.
- Public filters remain restricted to declared taxonomies and bounded search text.
- Row paths are sanitized and limited by the structured-data path resolver.
- Gallery and relationship collections remain bounded to 24 records.
- Query builders continue to reject arbitrary SQL and executable block templates.

## Verification status

Functional scope is complete for the 0.8 milestone, but this release candidate is not production-verified. Hosted CI, reproducible TypeScript/npm builds, and full WordPress/ACF/WooCommerce/accessibility/RTL/multisite/browser/performance matrices remain required before a stable `0.8.0` tag can be claimed.
