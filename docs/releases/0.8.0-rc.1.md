# Cresco Canvas 0.8.0-rc.1

> Release note lịch sử của release candidate 0.8.

## Scope đã hoàn tất

Release candidate này hoàn tất planned 0.8 Dynamic Data milestone ở mức source và checked-in runtime.

Scope được triển khai trong series 0.8 gồm:

- Dynamic scalar, image, gallery, relationship, repeater, flexible-content và sub-field bindings.
- Dedicated row image, row gallery và row relationship bindings trong Repeater/Flexible Content templates.
- Standard, advanced và filterable Loop builders.
- Bounded author, parent, search, date, include/exclude ID, taxonomy và meta queries.
- Server-side pagination, AJAX pagination, Load More, Infinite Scroll, URL/history synchronization và no-JavaScript fallbacks.
- Signed public query payloads, filter allow-lists, template allow-lists và anonymous rate limiting.
- Taxonomy facets, dependent live option counts, active-filter chips và Clear All controls.
- WooCommerce presets cho newest, featured, on-sale, in-stock, best-selling và top-rated products.
- ACF field schema discovery không expose raw values.
- Post-scoped Dynamic Data diagnostics cho duplicate Filterable Loop Instance IDs, missing row paths và loops không có enabled filters.

## Mới trong RC 1

- `cresco/acf-row-image`
- `cresco/acf-row-gallery`
- `cresco/acf-row-relationship`
- `POST /wp-json/cresco-canvas/v1/dynamic/facet-counts`
- `GET /wp-json/cresco-canvas/v1/dynamic/diagnostics/{postId}`
- Dependent taxonomy facet counts.
- Active-filter chips và Clear All.
- Final completion editor/frontend runtimes và release-package requirements.

## Security và bounds

- Facet-count requests yêu cầu exact HMAC-signed server payload.
- Public filters vẫn bị giới hạn vào declared taxonomies và bounded search text.
- Row paths được sanitize và giới hạn bởi structured-data path resolver.
- Gallery/relationship collections vẫn tối đa 24 records.
- Query builders tiếp tục từ chối arbitrary SQL và executable block templates.

## Trạng thái verification

Functional scope của milestone 0.8 được coi là complete ở mức source/checked-in runtime, nhưng release candidate này **chưa production-verified**.

Hosted CI, reproducible TypeScript/npm builds và full WordPress/ACF/WooCommerce/accessibility/RTL/multisite/browser/performance matrices vẫn bắt buộc trước khi có thể claim stable `0.8.0`.
