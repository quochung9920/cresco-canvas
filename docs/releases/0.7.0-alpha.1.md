# Cresco Canvas 0.7.0-alpha.1

## Added

- Native `cresco_template` entities edited with Gutenberg and revision support.
- Theme template types for Header, Footer, Single, Page, Archive, Search, and 404 documents.
- Display Conditions using allow-listed include/exclude rules for the entire site, front page, blog home, singular content, post types, post IDs, archives, taxonomies, search, 404, and authentication state.
- Priority-based template resolution when more than one published template matches.
- Header and Footer rendering through WordPress lifecycle hooks.
- Full-document rendering for Single, Page, Archive, Search, and 404 templates through a scoped renderer that retains `wp_head`, `wp_body_open`, and `wp_footer`.
- REST endpoints to list, create, update, and trash Theme Builder templates, plus an options endpoint for editor controls.
- Gutenberg document controls for template type, priority, and up to 24 display conditions.
- Regression coverage for template-type and display-condition sanitation.

## Security

- Theme templates accept only Core and Cresco blocks.
- Custom HTML, shortcode, freeform, third-party, and executable markup blocks are rejected by the REST write path.
- Template editing requires Page editing capabilities; item changes additionally require edit permission for the target template.
- Display rules, values, priorities, template types, and post IDs are normalized before storage or evaluation.

## Packaging

Release packages require the Theme Builder runtime manifest, JavaScript, stylesheet, and document renderer.

## Known limitations

- Hosted CI and WordPress runtime evidence are not yet available for the current `main` head.
- Header and Footer output depends on the active theme calling `wp_body_open` and `wp_footer` correctly.
- Full-document templates intentionally replace the active theme document shell while retaining critical WordPress lifecycle hooks; compatibility must be tested with target themes and plugins.
- Visual-condition previews, taxonomy term selectors, author/date conditions, template duplication, import/export, and conflict diagnostics remain future hardening work.
- This is an alpha source/runtime candidate, not a production-verified stable release.
