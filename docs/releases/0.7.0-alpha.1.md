# Cresco Canvas 0.7.0-alpha.1

> Release note lịch sử. Nội dung mô tả đúng scope của `0.7.0-alpha.1`, không phải trạng thái hiện tại.

## Đã thêm

- Native `cresco_template` entities được chỉnh bằng Gutenberg và có revision support.
- Theme template types cho Header, Footer, Single, Page, Archive, Search và 404 documents.
- Display Conditions bằng allow-listed include/exclude rules cho entire site, front page, blog home, singular content, post types, post IDs, archives, taxonomies, search, 404 và authentication state.
- Priority-based template resolution khi có nhiều published template cùng match.
- Header/Footer rendering qua WordPress lifecycle hooks.
- Full-document rendering cho Single, Page, Archive, Search và 404 templates qua scoped renderer vẫn giữ `wp_head`, `wp_body_open` và `wp_footer`.
- REST endpoints để list/create/update/trash Theme Builder templates, cùng options và diagnostics endpoints.
- Gutenberg document controls cho template type, priority và tối đa 24 display conditions.
- Theme Template list-table columns cho type, priority và normalized display conditions.
- Diagnostics cho invalid template type, empty template content, exclude-only rules và ambiguous published templates có cùng type/priority/conditions.
- Regression coverage cho template-type sanitation, display-condition sanitation và diagnostic conflict detection.

## Bảo mật

- Theme templates chỉ nhận Core và Cresco blocks.
- Custom HTML, shortcode, freeform, third-party và executable markup blocks bị REST write path từ chối.
- Chỉnh template yêu cầu Page editing capabilities; item change còn cần edit permission cho target template.
- Display rules, values, priorities, template types và post IDs được normalize trước storage/evaluation.
- Diagnostics chỉ đọc và giới hạn cho user có thể edit Pages.

## Packaging

Release package yêu cầu Theme Builder runtime manifest, JavaScript, stylesheet và document renderer.

## Giới hạn đã biết

- Hosted CI và WordPress runtime evidence chưa có cho `main` head tại thời điểm release note này.
- Header/Footer output phụ thuộc active theme gọi `wp_body_open` và `wp_footer` đúng cách.
- Full-document templates cố ý thay active theme document shell nhưng vẫn giữ critical WordPress lifecycle hooks; compatibility cần được test với target themes/plugins.
- Visual-condition previews, taxonomy term selectors, author/date conditions, template duplication và import/export còn là future hardening work.
- Diagnostics phát hiện ambiguous configuration nhưng không tự đổi priority/conditions.
- Đây là alpha source/runtime candidate, **không phải production-verified stable release**.
