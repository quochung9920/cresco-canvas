# Cresco Canvas 0.8.0-alpha.3

> Release note lịch sử. Nội dung mô tả đúng scope `0.8.0-alpha.3`.

## Đã thêm

- Server-rendered **Dynamic Gallery** block cho ACF Gallery fields và post-meta image lists.
- Server-rendered **Relationship Loop** cho ACF Relationship, Post Object và post-meta ID collections.
- Hỗ trợ attachment IDs, URLs và ACF-style image arrays trong gallery values.
- Field-inspection REST endpoint chỉ trả value type và count, không trả raw field content.
- Bounded gallery/relationship rendering với tối đa 24 items.
- Checked-in Gutenberg controls và responsive styles cho cả hai structured-data blocks.
- Regression coverage cho structured-value inspection, gallery bounds và unsafe gallery URLs.

## REST API

- `POST /wp-json/cresco-canvas/v1/dynamic/field-inspect`

Route yêu cầu Page editing capability và edit access tới post được inspect.

## Bảo mật và hiệu năng

- Field keys được normalize bằng `sanitize_key()`.
- Field inspection không trả raw values.
- External image URLs được sanitize và escape.
- Relationship loops chỉ render published posts và de-duplicate repeated IDs.
- Gallery/relationship collections bị giới hạn 24 records.
- Native attachment images dùng WordPress responsive image markup.

## Packaging

Release package yêu cầu:

- `build/dynamic-advanced.js`
- `build/dynamic-advanced.asset.php`
- `assets/css/dynamic-advanced.css`

## Giới hạn đã biết

- ACF Flexible Content và Repeater layout mapping chưa có.
- Relationship Loop dùng order do ACF/meta field trả về và chưa expose sorting riêng.
- AJAX filtering, faceted search, arbitrary meta-query construction và WooCommerce presets còn là future work.
- Hosted CI và full WordPress/ACF runtime verification chưa có cho `main` head tại thời điểm đó.
- Đây là alpha source/runtime candidate, **không phải production-verified stable release**.
