# Cresco Canvas 0.8.0-alpha.3

## Added

- A server-rendered **Dynamic Gallery** block for ACF Gallery fields and post-meta image lists.
- A server-rendered **Relationship Loop** for ACF Relationship, Post Object, and post-meta ID collections.
- Support for attachment IDs, URLs, and ACF-style image arrays in gallery values.
- A field-inspection REST endpoint that returns only value type and count, never raw field content.
- Bounded gallery and relationship rendering with a maximum of 24 items.
- Checked-in Gutenberg controls and responsive styles for both structured-data blocks.
- Regression coverage for structured-value inspection, gallery bounds, and unsafe gallery URLs.

## REST API

- `POST /wp-json/cresco-canvas/v1/dynamic/field-inspect`

The route requires Page editing capability and edit access to the inspected post.

## Security and performance

- Field keys are normalized with `sanitize_key()`.
- Field inspection does not return raw values.
- External image URLs are sanitized and escaped.
- Relationship loops render only published posts and de-duplicate repeated IDs.
- Gallery and relationship collections are limited to 24 records.
- Native attachment images use WordPress responsive image markup.

## Packaging

Release packages require:

- `build/dynamic-advanced.js`
- `build/dynamic-advanced.asset.php`
- `assets/css/dynamic-advanced.css`

## Known limitations

- ACF Flexible Content and Repeater layout mapping are not included yet.
- Relationship Loop currently uses the order returned by the ACF/meta field and does not expose independent sorting.
- AJAX filtering, faceted search, arbitrary meta-query construction, and WooCommerce presets remain future work.
- Hosted CI and full WordPress/ACF runtime verification are not yet available for the current `main` head.
- This is an alpha source/runtime candidate, not a production-verified stable release.
