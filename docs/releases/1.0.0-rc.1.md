# Cresco Canvas 1.0.0-rc.1

## Unified editor experience

Cresco Canvas now exposes one Gutenberg toolbar entry and one central workspace. The hub discovers installed Cresco editor modules, hides their separate toolbar entries, and lets users move between Design System, Templates and Components, Theme Builder, Dynamic Data, Interactions, and Forms from a single sidebar.

Existing module implementations remain registered to preserve saved content, permissions, REST contracts, and backward compatibility. The hub acts as the single navigation layer instead of replacing module state.

## Product scope

The 1.0 release candidate includes the functional scope completed through the 0.9 milestone:

- Native layout and responsive container system.
- Global design tokens and scoped site styles.
- Templates, synced components, and site kits.
- Theme Builder with display conditions and diagnostics.
- Dynamic fields, images, galleries, relationships, loops, advanced queries, AJAX filtering, facets, and WooCommerce presets.
- Tabs, accordion, modal, off-canvas, slider, disclosure, tooltip, sticky, and conditional visibility.
- Form builder with server validation, conditional and calculated fields, multi-step forms, secure uploads, CAPTCHA adapter architecture, submissions, email, webhooks, privacy tools, retention, and diagnostics.

## Unified runtime files

- `build/editor-hub.js`
- `build/editor-hub.asset.php`
- `assets/css/editor-hub.css`

The release packaging script requires these files and refuses to create an incomplete archive.

## Compatibility strategy

The hub does not delete or rewrite previously saved blocks or settings. Existing Cresco sidebars remain available internally and are opened through the single hub entry. This reduces toolbar clutter while retaining backward compatibility with 0.5–0.9 content.

## Release status

The planned 1.0 product scope and unified editor navigation are complete at source and checked-in runtime level. Hosted CI, full WordPress runtime verification, accessibility certification, security review, browser/theme/plugin matrices, and reproducible production packaging remain release-verification gates before a stable `1.0.0` tag.
