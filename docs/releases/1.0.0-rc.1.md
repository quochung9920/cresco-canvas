# Cresco Canvas 1.0.0-rc.1

> `1.0.0-rc.1` là **release candidate**, không phải stable commercial release.
>
> Đây là release note lịch sử của RC 1. Một số runtime surface được liệt kê bên dưới đã tiếp tục thay đổi sau mốc này; luôn kiểm tra current source/canonical docs khi phát triển trên `main`.

## Kiến trúc editor tại thời điểm RC này

Page có saved Cresco document dùng **Cresco Session v1** làm visual document source of truth. Standalone Cresco editor sở hữu Canvas, Inspector, Structure, responsive preview, undo/redo, History, AI import và Update cho Session đó.

WordPress vẫn là host cho authentication, permissions, media, Page records, routing, REST, preview URLs và frontend delivery. User-authored `post_content` được giữ làm fallback.

Primary standalone runtime surfaces tại thời điểm release note này gồm:

- `build/standalone-visual-editor.js`;
- `build/standalone-inspector-v2.js`;
- `build/standalone-ui-v3.js`;
- `build/standalone-page-settings.js`;
- `build/standalone-history.js`;
- `build/global-config-import.js`;
- `build/viewport-shell.js`.

Repository cũng chứa các native/older WordPress editor runtimes còn nằm trong product tree nơi service cũ vẫn load. Sự tồn tại của chúng **không có nghĩa Gutenberg là current Cresco Session document authority**.

## Release-engineering hardening

Nhánh `commercial/release-quality` đưa vào release infrastructure cho:

- authoritative ownership của các `build/` runtime từng được hand-maintain qua `runtime-src/`;
- clean deletion và reconstruction của complete production `build/` runtime;
- typecheck, JS/CSS/Markdown lint, unit tests, PHPUnit, PHPCS, runtime/version checks và dependency audits;
- deterministic, strict-allowlist versioned ZIP packaging;
- `SHA256SUMS`, file-level SPDX inventory và unsigned provenance metadata;
- two-clean-checkout reproducibility comparison;
- WordPress minimum/latest-minus-one/latest cùng PHP 8.1–8.4 coverage;
- Chromium, Firefox, WebKit, block-theme, classic-theme, ACF, WooCommerce và multisite smoke;
- automated axe checks và 50/200/500-node performance measurements;
- exact release-ZIP clean-install smoke;
- pinned historical upgrade smoke từ `0.9.0-rc.1`.

Đây chỉ là **gate definitions** cho tới khi chạy thành công trên exact commit/artifact. `NOT RUN`, `SKIPPED` và infrastructure/startup failure **không phải pass**.

## Stable-release blockers tại thời điểm RC 1

Stable `1.0.0` vẫn bị block cho tới khi toàn bộ P0 trong `docs/COMMERCIAL_HARDENING.md` và `docs/RELEASE_CHECKLIST.md` có objective evidence.

Đặc biệt:

- exact release ZIP phải pass clean install và upgrade;
- automated matrices phải pass;
- security review phải complete;
- manual accessibility/Edge/cache/optimization checks phải được ghi nhận.

Version phải giữ `1.0.0-rc.1` cho tới khi evidence đó tồn tại.
